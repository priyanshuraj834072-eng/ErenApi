API docs

Two endpoints. Put your key in the header and send JSON.

Verify a payment

Send a UTR or a transaction ID. Add the amount if it must match exactly.

POST/api/v1/payment/verify
Header
Authorization: Bearer YOUR_API_KEY
Request body


Response














FieldMeaning


successThe request itself went through.


receivedThe payment was found and matched.


amountAmount that came in. null when nothing matched.


transaction_idThe matched transaction ID.


utrUTR from the payment email, if it had one.


sender_nameName of the payer, or null.


already_verifiedSame payment was verified before. Never credit it twice.






HTTPWhen


200Verification ran. Read received for the result.


400Broken JSON, or a missing or badly formatted utr / transaction_id.


401API key missing or wrong.


500Server problem, usually the Gmail connection.
