Built to answer one question.
Has this customer actually paid? ErenApi checks real payment emails, not screenshots or claims.




Private key per merchant
Your key belongs to your account only. Replace it with a new one whenever you want.


Reads only your inbox
Connect the Gmail account that receives your payment alerts. Other merchants never touch it.


Match by UTR or ID
Use the UTR, or the transaction ID when no UTR exists. Add the amount to require an exact match. A payment that was already verified is flagged.







// docs
API reference
Two endpoints. Bearer key in the header, JSON in and out.




POST/api/v1/payment/verify


Header

Authorization: Bearer YOUR_API_KEY



Request by UTR
{
  "utr": "428917305561",
  "amount": 250
}


Request by transaction ID
{
  "transaction_id": "FMPIB2048117735",
  "amount": 250
}




amount is optional. When sent, it must match exactly.














FieldTypeMeaning


successbooleanThe request itself went through.


receivedbooleanThe payment was found and matched.


amountnumberAmount that came in. null when nothing matched.


transaction_idstringMatched transaction ID.


utrstringUTR from the payment email, if present.


sender_namestringName of the payer, or null.


already_verifiedbooleanSame payment verified before. Never credit it twice.






HTTPWhen


200Verification ran. Check received for the result.


400Broken JSON, or missing or badly formatted utr / transaction_id.


401API key missing or wrong.


500Server problem, usually the Gmail connection.








GET/api/v1/qr


Optional. Returns a standard upi://pay QR as an SVG image. Skip it if you already have your own QR.
