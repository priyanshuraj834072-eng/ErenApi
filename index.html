SECURITY FIRST

Designed with safety in mind.

A payment should only be accepted after the backend independently confirms a matching notification and records the transaction safely.

🔐 Protected credentials

Store OAuth credentials and secret API keys on the server, not in publicly accessible files.

🛡️ Server-side checks

Validate the amount, transaction identifier, merchant ownership and transaction status before returning success.

⚡ Safe retries

Use database transactions and unique transaction identifiers to avoid duplicate credits during simultaneous requests.
